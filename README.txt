Postcrastination — local browser app

Double-click Start Postcrastination.cmd to launch. Keep the terminal window open while using the app. Close it to stop the server.

This is a copy of the RPTPC desktop source. The original files have not been changed.
Node.js is installed in C:\Users\YOGA\Documents\Codex\runtimes\node-v24.21.0-win-x64.

Accounts require your Firebase web app configuration: copy .env.example to .env and fill in the four values, then restart the app. Do not put an OpenRouter key in these frontend settings.

The original Electron backend files were not present. Windows media detection and the connected AI planner require restoring those files. This setup runs the browser frontend.
